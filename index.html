跨域与测试说明
1. 跨域解决方案：终端运行 npm run serve 即可启动本地代理（自动为所有分片添加 CORS 头并绕过 Referer 防盗链）。
2. file:// 兼容：如直接双击打开 html，可将代理切换为 公共代理 (corsproxy.io) 绕过同源限制。
3. 0ms 秒开与伪头清洗：插件自带 stripTsHeader 自动切除伪装 PNG/JPEG 伪头，并基于 SegmentCache 实现 0ms 瞬间交付。
